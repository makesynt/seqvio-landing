Real workflow

Made to work where agents work

Seqvio is an open-source local framework with an optional agent skill. Review the plan, compile an ExplainerDocument, align narration, run QA, and render to MP4. Terminal and browser capture adapters are experimental.

  1. 01 Review EditorialPlan and VisualDesignBrief
  2. 02 Compile beats and observed evidence
  3. 03 Run QA and render locally

Open source · MIT

Teach your agent to explain

Install the renderer, then add the Seqvio skill to your coding agent. Capture adapters have separate experimental prerequisites.

Renderernpm install -g @seqvio/renderer
Agent skillnpx skills add makesynt/seqvio --skill seqvio -a codex -y

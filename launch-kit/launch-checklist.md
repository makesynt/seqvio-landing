# Product Hunt Launch Checklist

## Ready

- [x] Positioning centers on evidence-backed explainer videos for coding agents.
- [x] Landing hero uses the official Seqvio mark and a real product frame.
- [x] Landing demo is regenerated from the current EditorialPlan/ExplainerDocument narrative.
- [x] 240 x 240 thumbnail is prepared and under 3 MB.
- [x] Gallery images are regenerated from the current demo frames.
- [x] Tagline is within Product Hunt's 60-character limit.
- [x] Description is within Product Hunt's 500-character limit.
- [x] First maker comment and launch-day social copy are drafted.
- [x] Open Graph and canonical metadata use the deployed GitHub Pages URL.

## Before Scheduling

- [ ] Deploy the landing page to its final public HTTPS URL.
- [ ] Upload the demo to YouTube as Public or Unlisted and add its full URL to Product Hunt.
- [ ] Verify the GitHub README, npm package page, and landing page use the same positioning.
- [ ] Confirm the install command in a clean environment.
- [ ] Choose the closest three launch tags available in the live form.
- [ ] Add all makers and verify their Product Hunt profiles.
- [ ] Pick a launch date and schedule the post from the official launch dashboard.

## Launch Day

- [ ] Publish the first maker comment immediately after launch.
- [ ] Share the Product Hunt page and ask for feedback or comments, not votes.
- [ ] Reply to questions with specific examples and honest current limitations.
- [ ] Record recurring objections and add answers to the landing page or README.
- [ ] Check the landing video, GitHub links, npm link, and mobile layout after deployment.

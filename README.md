# Seqvio Landing Page

Static landing page for Seqvio launch and promotion.

## Preview

Open `index.html` directly in a browser, or serve this folder with any static server:

```bash
npx serve .
```

## Files

- `index.html` - page content and structure
- `styles.css` - responsive visual design
- `assets/videos/` - copied Seqvio demo media
- `tests/landing.test.mjs` - smoke test for required content and local assets
- `qa/` - generated screenshots from local visual checks

## Test

```bash
node tests/landing.test.mjs
```
